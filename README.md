# Requirements Specification and Analysis App

## Description
Spring Boot web application for managing software requirements.

## Features
- User registration & login
- Project management
- Use cases
- CRC cards
- Diagram generation (PlantUML / Nomnoml)

## Technologies
- Java 17
- Spring Boot
- Thymeleaf
- MySQL

## How to run
1. Clone the repository
2. Open in IntelliJ/Eclipse
3. Run RequirementsappApplication.java
4. Open http://localhost:8080
